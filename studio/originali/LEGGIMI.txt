PACCHETTO IMMAGINI · MIGLIORE – ESTETICA AVANZATA
=================================================

Cosa contiene
- foto/          le 6 foto del centro, IDENTICHE agli originali ricevuti (solo rinominate)
- logo/          il logo ufficiale ritagliato dallo screenshot ricevuto, senza payoff:
                 versione trasparente, versione su sabbia #F4DBCA, farfalla per le icone
- condivisione/  immagine 1200×630 per le anteprime dei link (logo + foto 01 su sabbia)

Regole
- Le foto non vanno ritoccate: niente filtri, niente correzioni di luce o colore,
  niente ritagli dei file, niente ingrandimenti. Si fanno solo ridimensionamento
  e conversione in AVIF e WebP. La sfumatura nel sabbia la fa il CSS della pagina.
- Il logo trasparente è ottenuto togliendo il fondo sabbia (#F4DBCA) dallo screenshot,
  senza ridisegnarlo. Va usato solo su fondi chiari (sabbia, sabbia chiara, bianco).
- L'immagine di condivisione è l'unico file composto: contiene il logo e la foto 01
  ridimensionata e inquadrata, senza ritocchi.

Come caricarlo su GitHub
1. Apri il repository su github.com.
2. In alto a sinistra scegli il branch di lavoro (non main).
3. Add file → Upload files → trascina migliore-immagini.zip → Commit changes.
4. Incolla in Claude Code il prompt dello Step 2.
